# Aircon service cards

These are interactive panels extracted from the Aircon app's full screens.
An order, installation appointment, calendar update or payment panel can be
mounted independently, with its own native components, data and actions.

The [catalogue](catalogue.json) contains 14 state variants grouped by service
owner: shopping, logistics, installation, calendar and payment. Those groups
are parts of the Aircon journey, not separate app projects.
