# Aircon screen states

These are twelve screens of one Aircon app and service journey, not twelve apps.

| Folder | Screen |
| --- | --- |
| `aircon-01` | Product details |
| `aircon-02` | Order details |
| `aircon-03` | Desktop order card |
| `aircon-04` | Logistics update |
| `aircon-05` | Installation booking |
| `aircon-06` | Expanded timeslots |
| `aircon-07` | Selected timeslot |
| `aircon-08` | Appointment and calendar |
| `aircon-09` | Undo calendar update |
| `aircon-10` | Technician arriving |
| `aircon-11` | Materials payment due |
| `aircon-12` | Payment completed |

Each folder holds the reference, semantic mapping and native components for
that screen. Smaller mountable panels extracted from these screens live in
[`../service-cards/`](../service-cards/README.md).
